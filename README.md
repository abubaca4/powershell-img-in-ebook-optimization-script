# Оптимизатор EPUB и FB2 файлов

Набор скриптов для оптимизации электронных книг в форматах EPUB и FB2 с помощью сжатия изображений без потерь качества.

## Описание

Скрипты выполняют поиск и обработку файлов электронных книг, извлекают изображения, сжимают их без потерь качества и переупаковывают книги. Если размер файла после оптимизации не уменьшается, используется оригинальная версия.

## Особенности

* **Поддержка форматов:** EPUB, FB2, FB2.ZIP
* **Без потерь качества:** используется lossless-оптимизация изображений
* **Многопоточная обработка:** поддержка параллельной обработки файлов
* **Сохранение структуры:** сохраняется оригинальная структура папок
* **Проверка результатов:** файл заменяется только если его размер уменьшился
* **Ускорение через 7-Zip:** поддержка внешней утилиты для ускорения распаковки и применения максимального уровня сжатия (`-mx9`)

## Требования

* PowerShell 7 или новее (не Windows PowerShell 5.1)
* **Внешние зависимости:** содержимое репозитория `powershell-img-optimization-script` должно находиться в той же папке
* **Архиватор 7-Zip (опционально, но крайне рекомендуется):** для ускорения упаковки/распаковки и лучшего сжатия. Консольная команда `7z` должна быть доступна в системе (прописана в переменной окружения `PATH`).

> 💡 **Примечание:** Если 7-Zip не установлен или не найден в `PATH`, скрипты автоматически переключатся на встроенные командлеты PowerShell (`Expand-Archive` и `Compress-Archive`). Это позволит скрипту работать, но процесс упаковки/распаковки будет заметно медленнее.

## Установка

1. Установите PowerShell 7.
2. Установите [7-Zip](https://www.7-zip.org/) и убедитесь, что путь к папке с программой (например, `C:\Program Files\7-Zip`) добавлен в системную переменную `PATH`.
3. Склонируйте необходимые репозитории в одну рабочую директорию:

```powershell
# Клонируйте основной репозиторий
git clone [https://github.com/abubaca4/powershell-img-in-ebook-optimization-script](https://github.com/abubaca4/powershell-img-in-ebook-optimization-script)

# Клонируйте репозиторий с оптимизаторами изображений в ту же папку
git clone [https://github.com/abubaca4/powershell-img-optimization-script](https://github.com/abubaca4/powershell-img-optimization-script)
```

Структура папок должна выглядеть так:
```text
ваша-папка/
├── epub_opt.ps1
├── fb2_opt.ps1
├── png_opt.ps1
├── jpg_opt_losless.ps1
├── gif_opt_losless.ps1
├── и другие файлы из powershell-img-optimization-script
```
* Скачайте exe оптимизаторов изображений и расположите их как это описано в [powershell-img-optimization-script](https://github.com/abubaca4/powershell-img-optimization-script)

## Использование
### Оптимизация EPUB файлов
```powershell
./epub_opt.ps1 -InputPath "C:\путь\к\исходным\файлам" -OutputPath "C:\путь\к\результату" [-j <потоки>] [-AsciiTempMode]
```

#### Параметры:
* InputPath (обязательный) - путь к папке с исходными EPUB файлами
* OutputPath (обязательный) - путь к папке для сохранения оптимизированных файлов
* j - режим многопоточности:
    * 0 - использовать все ядра процессора (параллельная обработка файлов)
    * 1 - последовательная обработка
    * \>1 - заданное число потоков
* AsciiTempMode - использовать режим ASCII для временных файлов (полезно при проблемах с путями, содержащими Unicode символы)

## Оптимизация FB2 файлов
```powershell
./fb2_opt.ps1 -InputPath "C:\путь\к\исходным\файлам" -OutputPath "C:\путь\к\результату" [-j <потоки>] [-AsciiTempMode]
```

**Параметры:** аналогичны параметрам для EPUB
## Принцип работы
### Для EPUB файлов:
1. Находятся все EPUB файлы во входной папке
2. Каждый файл распаковывается во временную папку
3. Находятся и оптимизируются все изображения (PNG, JPG, GIF)
4. Книга собирается обратно с учетом спецификации EPUB (файл mimetype упаковывается без сжатия)
5. Сравнивается размер нового и оригинального файла
6. Сохраняется файл меньшего размера
### Для FB2 файлов:
1. Находятся FB2 и ZIP файлы (содержащие FB2) во входной папке
2. Определяется кодировка FB2 файла (UTF-8, UTF-16, Windows-1251 и др.)
3. Извлекаются изображения из base64-блоков <binary>
4. Изображения декодируются, оптимизируются и кодируются обратно в base64
5. Для ZIP файлов: извлекается содержимое, обрабатываются FB2 файлы, перепаковывается архив
6. Сравнивается размер нового и оригинального файла
7. Сохраняется файл меньшего размера

### Особенности многопоточности
* Когда скрипт запущен в однопоточном режиме (-j 1): оптимизаторы изображений работают в многопоточном режиме (используют все ядра)
* Когда скрипт запущен в многопоточном режиме (-j 0 или -j >1): оптимизаторы изображений работают в однопоточном режиме

Это сделано для оптимального распределения ресурсов и предотвращения перегрузки системы.
### Сортировка файлов

Все найденные файлы сортируются по размеру (от большего к меньшему). Это позволяет начать обработку самых больших файлов как можно раньше, что особенно важно при многопоточной обработке, когда оптимизация изображений ограничена одним потоком.
## Примеры использования
### Пример 1: Оптимизация EPUB с использованием всех ядер
```powershell
./epub_opt.ps1 -InputPath "D:\Книги\EPUB" -OutputPath "D:\Книги\Оптимизированные" -j 0
```
### Пример 2: Оптимизация FB2 с 4 потоками
```powershell
./fb2_opt.ps1 -InputPath "D:\Книги\FB2" -OutputPath "D:\Книги\Оптимизированные" -j 4
```
### Пример 3: Последовательная обработка EPUB
```powershell
./epub_opt.ps1 -InputPath "D:\Книги\EPUB" -OutputPath "D:\Книги\Оптимизированные" -j 1
```
## Примечания
* Скрипты не изменяют оригинальные файлы, а создают копии в выходной папке
* При запуске скрипт выведет в консоль строку Использование 7-Zip: True/False, чтобы вы могли сразу понять, задействован ли быстрый режим архивации.
* Процесс можно прервать в любой момент сочетанием клавиш Ctrl+C
